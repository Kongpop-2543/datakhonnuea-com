ดึงข้อมูลหุ้นด้วย Python

2 Jul 2024

สวัสดีครับ วันนี้ผมจะพาทุกคนมารู้จักกับ Library ยอดฮิตตัวนึงที่เราสามารถดึงราคา Open High Low Close Volume ของตลาดหุ้นออกมาได้ ซึ่งวิธีการดึงมีได้หลากหลายวิธีมากๆ แต่วิธีนี้เป็นวิธีที่ผมใช้ประจำในการดึงข้อมูลครับ

yfinance เป็น Library open-source ของ yahoo website ที่เราสามารถใช้งานได้ฟรีสำหรับการดึงข้อมูล market data ต่างๆ ซึ่งเราสามารถดึงข้อมูลได้ออกมาหลากหลาย ไม่ว่าจะเป็น

  • income statement
  • balance sheet
  • cash flow statement
  • Open High Low Close Volume

อ่ะ ไม่รอช้า เราไปเริ่มกันเลยดีกว่า

Coding Hand on

Install&Import Library

!pip install yfinance

โดยเป็นการติดตั้งเพียงครั้งเดียว ครั้งหน้าเราสามารถโหลด Library นี้มาใช้งานได้เลยเพียงแค่ใช้คำสั่ง import library

import yfinance as yf

download data

yf.download('AMZN' , start = start="2017-01-01", end="2017-04-30")

ซึ่งผลลัพธ์ก็จะได้หน้าตาออกมาเป็น format pandas dataframe เราสามารถนำไปใช้ต่อได้แบบสบายๆ เลยครับ

แต่ถ้าใครอยากจะได้แค่บาง Column เท่านั้น เราก็สามารถ specific แค่บางคอลัมณ์ก็ได้เช่นกันครับ ตัวอย่างเช่น

yf.download('AMZN' , start = start="2017-01-01", end="2017-04-30")['Close']

โดยผลลัพธ์จะออกมาเพียง 1 คอลัมณ์ตามที่เราเลือกเท่านั้น ซึ่งวิธีการ manipulate data ผมก็เขียนในบทความก่อนหน้าแบบเบื้องต้นแล้ว ถ้าใครสนใจสามารถคลิกที่นี่ได้

ซึ่งพอเราทำได้ 1 ตัวแล้วสิ่งที่ผมชอบที่สุดอีกอย่างหนึ่งในการเขียนโค้ดเลยก็คือการใช้ Looppppp!!!!! เพราะเราไม่ต้องเสียเวลามาไล่เปลี่ยน Ticker ทีละตัว แต่เราสามารถเลือก Ticker ที่เราต้องการ และให้ Python run loop จนจบได้เลย ตัวอย่างโค้ดนี้เลยครับ

stocks = ['AMZN', 'MSFT', 'INTC']

Get market data

เราสามารถดึงข้อมูลสำหรับข้อมูลอื่นๆ ของ yfinance ได้เช่นกันไม่ว่าจะเป็น income statement, balance sheet, cash flow statement

โดยวิธีการดึงก็ง่ายแสนง่าย สามารถทำตามได้ทันทีเลย ตัวอย่างเช่น

amzn = yf.Ticker("AMZN")

# Get income statement
amzn.income_stmt

# get balance sheet data
amzn.balance_sheet

# get cashflow data
amzn.cashflow

ซึ่งถ้าเราอยากจะได้หลายๆ ตัวพร้อมกัน ก็นั่นแหละครับ สามารถใช้ loop เพื่อดึงหลายๆ ตัวพร้อมกัน เก็บไว้ใน dataframe และนำไปวิเคราะห์ข้อมูลต่อได้แบบชิลๆ เลย

สรุป

yfinance สามารถดึงข้อมูลของ หุ้นหรือ สินทรัพย์ทุกสินทรัพย์ที่มีอยู่ในเว็บไซต์ yahoo finance โดยเราสามารถดึงได้ฟรีและใช้งานง่าย สามารถนำไปวิเคราะห์ข้อมูลต่อก็สะดวกสบายมากๆ
