Zettelkasten Smart Notes Step by Step with Obsidian

15 Apr 2026

Reference : https://www.youtube.com/watch?v=ziE6UExsOrs

เนื้อหาในวิดีโอนี้สอน Step-by-Step สำหรับจดโน๊ต 1 เรื่องมี Step อะไรบ้าง
โดยมีลำดับตามนี้

  1. จด Fleeting Note เป็นไฮไลท์ส่วนที่สำคัญของเรื่องที่สนใจ
  2. สร้าง Literature Note ใหม่โดยอิงจาก Fleeting Note ที่จดไปก่อนหน้า โดยใช้ภาษาของตัวเอง
  3. สร้าง MOC และ Permanent Note ในเรื่องที่สนใจ
  4. กำหนดหัวข้อของ MOC และ Permanent Note ว่าจะประกอบหัวข้อไหนบ้าง
  5. ใน Permanent Note ให้ใส่ reference ของ Literature Note ด้วย จะได้รู้ว่า Idea นี้มาจาก Note ไหน
  6. นำหัวข้อ Permanent Note ทั้งหมดมาใส่ไว้ใน MOC เรื่องใหม่
  7. สร้าง Project ใหม่เพื่อเผยแพร่

โดย Permanent Note จะต้องเป็น Atomic 1 เรื่อง 1 Note หรือ 1 ความคิด
