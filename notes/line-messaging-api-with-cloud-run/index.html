Line Messaging API with Cloud Run

26 Oct 2025

เรื่องมันมีอยู่ว่า ผมได้เจอโจทย์ทางธุรกิจ ที่เราไม่สามารถรู้ได้เลยว่า สินค้า Inbound เข้าคลังสินค้าของเราตอนไหนแล้ว นั่นจึงเป็นเหตุผลที่ผมอยากมาทำ Line Messaging มาบอกผู้ใช้ตอนที่ของเข้า

ในบทความนี้ผมอาจจะไม่ได้จับมือทำ Step-by-Step เลย เพียงแค่ถ่ายทอดสิ่งที่ได้ทำมา ว่าทำอะไรมาบ้างเท่านั้นนะครับ ขออนุญาต เริ่มเลยแล้วกัน

เนื่องจาก LINE มี LINE Messaging API ที่เปิดให้เราสร้างบอทได้ฟรี
เลยคิดว่าเป็นโอกาสดีที่จะลองทำโปรเจกต์ ตั้งแต่เขียนโค้ดบน localhost, ทดสอบด้วย ngrok, ไปจนถึง deploy ขึ้น Cloud Run ของ Google Cloud

เป้าหมายของโปรเจกต์:

  • อยากสร้าง LINE Bot ง่าย ๆ ที่รับข้อความจากผู้ใช้ แล้วตอบกลับข้อความนั้นตามเงื่อนไขที่ผู้ใช้ส่งมา แบบอัตโนมัติ (“echo bot”) ซึ่งสามารถต่อยอดไปถึงโจทย์ที่ผมอยากทำได้

เครื่องมือที่ใช้

  • LINE Messaging API
  • FastAPI
  • ngrok
  • Cloud Run
  • Python

Library สำหรับการพัฒนาในครั้งนี้

จริงๆ ดูไฟล์ใน requirements.txt ก็ได้นะครับ แต่ผมจะนำมาใส่ในนี้ด้วย เพราะเห็น Blog อื่นๆ เค้าก็ใส่กันเยอะดี

  • fastapi
  • line-bot-sdk
  • uvicorn
  • python-dotenv

สิ่งที่ได้เรียนรู้

  • สิ่งที่ผมได้เรียนรู้คือ ทักษะการออกแบบของการดึง Secret Manager เราจะไม่ใช้ Python ในการดึง secret manager แต่จะฉีด secret key ต่างๆ ไว้ตอน deploy เลย เนื่องจาก ถ้าใช้ python ในการดึง secret แบบนี้ ทุกครั้งที่มีคนทักมาหา line bot จะถูกเรียก API 1 ครั้ง ซึ่งทั้งช้าและเสีย limit รอบในการดึงแต่ละครั้ง ถึงแม้ว่าข้อดีของมันจะมีความปลอดภัยสูงก็ตาม ดังนั้นการฉีด secret key เข้า cloudrun โดยตรงเลยจะเหมาะกับ use case ของ LINE Bot มากกว่า
  • การสร้าง Webhook บน Cloud Run ที่รอรับ Event จาก Line API จากข้อความที่ผู้ใช้ส่งมาให้

Environment Setup

  • สิ่งที่ต้องมีบนเครื่องของเราก็คือ ngrok ถ้าใครไม่มีไปติดตั้งก่อน
  • Python
  • สมัครใช้บริการ Google Cloud Platform ให้เรียบร้อย
  • สร้าง LINE Developer Account และ LINE Official Account สำหรับทดสอบให้เรียบร้อย

Development on Localhost

  • สร้างโปรเจกต์เบื้องต้น และสร้าง Virtual Environment สำหรับพัฒนาโปรเจคก์นี้
  • สำหรับโค้ดต่างๆ ผม push ไว้บน Github เรียบร้อยแล้ว หากใครสนใจก็เข้าไปดูได้ที่ลิงค์นี้
  • หลังจากโค้ดของผมเขียนเสร็จแล้ว ผมก็จะรันและทดสอบบน localhost ด้วยคำสั่ง
uvicorn main:app --host 0.0.0.0 --port 8080
  • จากนั้นเปิดอีกเทอร์มินัล เพื่อ forward Port ของผมไปบนเว็บไซต์ให้ Line สามารถส่ง API มาหาเราได้
ngrok http 8080
  • หลังจากที่ ngrok สร้าง public url ให้กับเราแล้ว เราจะ Copy Url นี้ไปวางไว้บน LINE Developers Console → Webhook URL
  • กด “Verify” → ถ้าโชว์ “Success!” แปลว่าสามารถส่งข้อความตอบกลับไปหา User สำเร็จแล้ว 🎉
  • รูปภาพปลากรอบ

การเตรียมสำหรับ Deploy (Pre-deployment)

หลังจากที่พัฒนาเสร็จแล้ว ก็ทำการสร้าง Dockerfile ขึ้นมาอีก 1 ไฟล์ ใช้สำหรับ Deploy กับ Cloudrun ซึ่งนั่นแหละครับ! โค้ดอยู่บน Github เช่นเดิม

หลังจากมี Dockerfile แล้ว ผมก็ทำการ build image เพื่อทดสอบผ่าน Docker Desktop ก่อน ภาษาทางเทคนิค เค้าเรียกอะไรนะ CI/CD

หลังจากผ่านแล้วผมก็ทำการ push โค้ดของผมไว้บน Gitgub Repository เลยและไปต่อกันใน part Deploy Cloud Run!

☁️ การ Deploy ขึ้น Cloud Run

  1. ก่อนจะเริ่ม อย่าลืมว่าต้องมีบัญชี Google Cloud ก่อน และ enabled API ที่เกี่ยวข้องสำหรับ Project นี้ด้วยครับ Part นี้ไม่ยาก เพราะสิ่งที่เราต้องทำมีแค่
  • เลือก service
  • หลังจากเลือก GCP จะเด้งหน้าต่าง pop-up มาให้เรากด enabled ก็เป็นอันเสร็จ

2. หลังจาก enabled เรียบร้อยแล้ว เราก็ทำการสร้าง Secret Manager และให้สิทธ์ access secret manager ใน Service Account ที่ทาง Cloud Run สร้างมาให้เรา

3. หลังจากนั้นก็สร้าง Cloud Run ได้เลยครับ อย่าลืมว่าต้องฉีด Environment Variable ตอนสร้างด้วยจะได้ไม่ต้องไปรบกวน Python ยิง API ไปหา secret manager ทุกรอบ

Error List ที่เจอใน Project นี้

แน่นอนว่า จะต้องเจอ Error กันแน่นอนอยู่แล้วตอนพัฒนา แต่ว่าพอเจอแล้ว เราสามารถแก้ไขปัญหามันได้ไหม นั่นต่างหากที่สำคัญ

ซึ่ง Error ที่เจอได้แก่

SSL Certificate Verification Failed
  • SSL Certificate Verification Failed อันนี้เป็น Error ตอนที่จะส่งข้อความตอบกลับไปหา User เกิดขึ้นเกิดจาก python บน macos ไม่มี root certificates หรือ CA bundle ติดตั้งอยู่ในเครื่อง ทำให้ไม่สามารถส่งข้อความตอบกลับไปยัง LineServer ได้

ซึ่งวิธีการแก้ปัญหาของผมคือ

พิมพ์คำสั่งนี้ไปบน terminal คือการ 🔧 ติดตั้ง “ใบรับรองความปลอดภัย (SSL Certificates)” ให้ Python บน macOS

/Applications/Python\ 3.11/Install\ Certificates.command
Cloud Run Build Error (Build Process)

Error ที่เจออาจจะเดาได้ว่าเกิดจาก Port Cloud Run Container ไม่สามารถ start ได้ภายในเวลาที่กำหนด ซึ่งพอถามต่อว่าทำไม ก็เพราะว่า Cloud Run ไม่สามารถดึง Secret ได้ ซึ่งพอถามต่อว่าทำไม ก็เพราะว่า ผมไม่ได้กำหนด Environment Variable ให้ Cloud Run ระบบจึงไม่รู้ว่าจะต้องไปดึงจากไหนจนหมดเวลานั่นเอง

สรุปก็คือ : แอปตายระหว่างสตาร์ทเพราะ secret ไม่ได้ค่า → เลยไม่ทันเปิดพอร์ต

ซึ่งวิธีการแก้ปัญหาของผมคือ

  • ให้ Service Account access สำหรับเข้าถึง Secret Manager Secret Accessor Role
  • ฉีด Environment Variable เข้าไปตอน Build Cloud Run
