คำสั่งพื้นฐาน Pandas สำหรับ Analyzing Sales Data

11 May 2024

สวัสดีครับ วันนี้ผมจะมาเขียน Blog เกี่ยวกับตัวอย่างโค้ด ที่ใช้สำหรับ manipulate ด้วย pandas กันครับ เพื่อเก็บไว้ดูย้อนหลังด้วยตัวเอง หรือว่าให้เพื่อนๆ ที่แวะเข้ามาดูกันครับ

Pandas คืออะไร? Pandas คือ library ที่เราสามารถใช้งานกับ structure data หรือว่า data ที่มีประกอบไปด้วย row และ column เช่น Table ใน Spreadsheet Excel, Google Sheet

ผมจะไม่สาธิตวิธี install pandas หรือ ติดตั้งนะครับ เพราะคิดว่าทุกๆ คนสามารถทำได้อย่างแน่นอน หรือหากถ้าสงสัยสามารถคลิกได้ที่ ลิงค์นี้โลด

ซึ่ง มาเริ่มกันเลย

import pandas and read csv

import pandas as pd
df = pd.read_csv("store/sample-store.csv")

ทำความเข้าใจข้อมูลที่อยู่ตรงหน้า

function head() ในตัวอย่างนี้ จะโชว์ผลลัพธ์ 10 แถวบนแรกของ data frame ครับ

df.head(10)

หรือถ้าหากต้องการโชว์ 10 แถวล่างสุดท้ายสามารถทำได้โดยใช้ function tail()

df.tail(10)

หรือถ้าต้องการแสดงจำนวน Column และ Row สามารถทำได้โดยใช้ shape

df.shape

อีก function นึงที่น่าสนใจมากก็คือ info() คือ method หรือก็คือ function ที่สร้างมาโดย object ใน concept OOP(Object Oriented Programming) ส่วนตัวมองว่ามีประโยชน์มากๆ เนื่องจากแสดงผลทั้งจำนวน row, ชื่อ columns, Data type, จำนวน row

df.info()

recheck missing values

ใช้ function isna() ในการเช็คว่า value ในคอลัมณ์ไหนที่มี missing values บ้าง แล้วเราใช้ sum() ในการรวมคอลัมณ์ที่มี missing values

null_table = df.isna().sum()
null_table

จัดการกับวันที่

function ที่ใช้จัดการกับวันที่ ผมใช้ function to_datetime ครับ

ซึ่ง aguement จะใช้ format date เดิมของวันที่เพื่อนๆ ดังนั้นใช้สังเกตโครงสร้างของวันที่ใน table ของตัวเองก่อนนะครับ

ตัวอย่าง เช่น format date แบบเดิมเราคือ 1/23/2019 หรือ เดือน/วัน/ปี ให้เราใส่ format '%m/%d/%Y'

ซึ่ง output หน้าตาจะได้ออกมาเป็นแบบนี้ครับ และเราจะสามารถจัดการกับ date ได้ง่ายขึ้นครับ

Data Analysis Part

Part นี้จะเป็น Part ที่ผม Analyst ข้อมูล โดยใช้ Python Pandas library ครับ

1. Your friend ask for California data, filter it and export csv for him

วิธีที่ผมทำก็คือ

  1. import csv เพื่อ export csv
  2. Select Column ที่เป็น California
  3. ใช้ function to_csv เพื่อบันทึกและส่งต่อให้เพื่อน
import csv
California_data = df[df['State'] == "California"]
df.to_csv("store/California_data.csv")

2. your friend ask for all order data in California and Texas in 2017 (look at Order Date), send him csv file

  • Select Order Date and transform to format date
df['Order Date'] = pd.to_datetime(df['Order Date'], format='%m/%d/%Y')
  • Filter California and Texas in State Column
cari_and_texas = df[(df["State"] == 'California') | (df["State"] == 'Texas')]
  • Filter Year == 2017 และฝากไว้ที่ตัวแปร filter_cari_and_texas
filter_cari_and_texas = cari_and_texas[cari_and_texas['Order Date'].dt.strftime('%Y') == '2017']
  • ใช้ function to_csv เพื่อบันทึกและส่งต่อให้เพื่อน
filter_cari_and_texas.to_csv("store/filter_cari_and_texas.csv")

3. how much total sales, average sales, and standard deviation of sales your company make in 2017

  • filter Order Date year == 2017 และฝากไว้ที่ตัวแปร sale_com
sale_com = df[pd.to_datetime(df['Order Date'], format='%m/%d/%Y').dt.strftime('%Y') == '2017']
  • หาค่า sum, mean, standard deviation
    • round ใช้สำหรับปรับจุดทศนิยมให้เหลือ 2 ตัว
    • agg เป็น method ที่ไว้สำหรับหาค่าสถิติจากคอลัมณ์ที่เราเลือก
    • transpose() สลับแกนจากคอลัมณ์เป็น row จาก row เป็นคอลัมณ์
sale_com = round(sale_com[["Sales", "Profit"]].agg(["sum", "mean", "std"]),ndigits = 2).transpose()

4. which Segment has the highest profit in 2018

  • filter year == 2018 และฝากไว้ที่ตัวแปร profit_seg
profit_seg = df[pd.to_datetime(df['Order Date'], format='%m/%d/%Y').dt.strftime('%Y') == '2018']
  • group by เพื่อหา segment ที่เยอะที่สุด
profit_seg.groupby("Segment")['Profit'].agg("sum").reset_index()

4. which top 5 States have the least total sales between 15 April 2019 – 31 December

  • เลือก date
    • ใช้ method between เพื่อเลือกวันที่ 2019-04-15 ถึงวันที่ 2019-12-31 และฝากไว้ที่ตัวแปร least_sale
least_sale = df[pd.to_datetime(df['Order Date'], format='%m/%d/%Y')\
    .dt.strftime('%Y-%m-%d').between('2019-04-15', '2019-12-31')]
  • sum column Sales และ group by ด้วย column State
least_sale = least_sale.groupby('State')['Sales'].agg("sum")
  • sort acesending order เพื่อหายอดขายที่น้อยที่สุด 5 อันดับแรก และ function reset_index() เพื่อ เปลี่ยน row name state ให้อยู่ในรูปแบบ column
least_sale.sort_values().head(5).reset_index()

5. what is the proportion of total sales (%) in West + Central in 2019

  • filter year == 2019
prop_sale = df[pd.to_datetime(df['Order Date'], format='%m/%d/%Y').dt.strftime('%Y') == '2019']
  • find total sales ทั้งหมด และ total sale ของ region ฝากไว้ที่ตัวแปร prop_sale_w_r เพื่อนำมาเปรียบเทียบกัน 
total_sales_w_r = prop_sale['Sales'].sum()
prop_sale_w_r = round(prop_sale.groupby('Region')['Sales'].agg('sum').reset_index(),ndigits=2)
  • สร้าง column ใหม่ชื่อว่า Propotion และเพิ่ม value จากการคำนวน propotion ของแต่ละ Region West + Central
prop_sale_w_r['Propotion'] = round(prop_sale_w_r['Sales'] / total_sales_w_r * 100, ndigits=2)
  • filter Region == West + Central
prop_sale_w_r = prop_sale_w_r[(prop_sale_w_r['Region'] == 'West') | (prop_sale_w_r['Region'] == 'Central')]

6. find top 10 popular products in terms of number of orders vs. total sales during 2019-2020

  • เลือกข้อมูลที่เป็น year 2019 และ 2020
top_sale = df[pd.to_datetime(df['Order Date'], format='%m/%d/%Y').dt.strftime('%Y').between('2019', '2020')]
  • sum และ count Column Sales และ reset_index() เพื่อสามารถนำข้อมูลไปใช้งานต่อ
top_sale = top_sale.groupby('Product Name')['Sales'].agg(['count', 'sum']).reset_index()
  • rename column และ sort data
top_sale = top_sale.rename({'Product Name':'Prodcut Name', 'count':'Count Orders', 'sum':'Sum Sales'}, axis = 'columns')\
    .sort_values(['Sum Sales', 'Count Orders'],ascending = False)\
        .head(10)
