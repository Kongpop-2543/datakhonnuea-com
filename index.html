Orders in. Dashboards out.

I'm Kong, an IT coordinator in Bangkok, building toward data engineering. I connect marketplaces to the order system, load the data into BigQuery with Python jobs on Cloud Run, and put it in front of the business in Looker Studio.

Selected work

Cloud Run pipelines and a sales dashboard

Python pipelines packaged with Docker and deployed as Cloud Run Jobs, loading data into BigQuery. On top sits a Looker Studio dashboard that compares actual sales with targets, fed by a BigQuery materialized view.

Python, Docker, Cloud Run Jobs, BigQuery, Looker Studio

Sales reconciliation across channels

A pandas pipeline that checks Shopee, Lazada, TikTok and direct-sale orders against Odoo, including prorated seller discounts. Google Sheets holds the source of truth, and I'm evaluating an Apps Script web app as a shared front end with access control.

Python, pandas, Google Sheets, Apps Script, Odoo

Marketplace connections to the order system

API integrations that bring each sales channel into Mycloud OMS, with testing across Lazada, Shopee, TikTok and Shopify so every channel's orders land in one place.

Shopify, Shopee, Lazada, TikTok Shop, Mycloud OMS

Odoo ERP after go-live

Coordinating post-launch work with the implementation vendor: tracking bugs and feedback, writing structured handoffs that developers can act on, and scripting bulk product changes through Odoo's XML-RPC API.

Odoo, XML-RPC, Python
